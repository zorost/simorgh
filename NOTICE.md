# Notice

## Texts

Classical Persian poems in this project are public-domain literary works.
The compilation, identifiers, biographies, metres, and Persian summaries
come from [Ganjoor](https://ganjoor.net) via
[ganjoor/ganjoor-data](https://github.com/ganjoor/ganjoor-data).

Ganjoor-data declares no license. Treat the compilation as Ganjoor's.
Do not republish their JSON tree as if it were yours. Simorgh fetches
it at build time and at read time, and ships only a compact atlas plus
a canon search slice.

## Code

Simorgh source code is MIT. That license covers our scripts, interface,
theme lexicon, and graph construction. It does not cover Ganjoor's files.

## What we do not ship

- API keys
- user accounts
- comments or bookmarks
- the full 132k-poem JSON tree
- English poem summaries generated by a third-party crawl
