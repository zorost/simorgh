## معرفی پروژه

**سیمرغ** یک نقشهٔ دانش تعاملی بر پایهٔ پیکرهٔ غنی [گنجور](https://ganjoor.net) است که ارتباطات ساختاری شعر فارسی را به تصویر می‌کشد:

- **۲۳۴ سخنور کهن و معاصر**: از سده‌های نخستین تا دوران معاصر (رودکی، فردوسی، خیام، نظامی، عطار، سنایی، مولانا، سعدی، حافظ، جامی، صائب، بیدل، پروین، شهریار و دیگر بزرگان ادب).
- **مکاتب و سبک‌های ادبی**: دسته‌بندی بصری بر اساس سبک‌های خراسانی، عراقی، هندی، بازگشت و معاصر.
- **نمای هندسهٔ مقدس و اسطرلاب**: پس‌زمینه و مداربندی کهکشانی الهام‌گرفته از اسطرلاب و نگاره‌های تاریخی سخنوران.
- **جستجوی نرمال‌شدهٔ فارسی**: نمایهٔ سریع BM25 روی ۳٬۷۷۶ شعر کانونی با نرمال‌سازی کامل نویسه‌ها (ی/ک، حذف اعراب، نیم‌فاصله‌های اختیاری).
- **کاوشگر و گفتگوی مستند ادبی**: موتور استدلال درون‌مرورگری که پاسخ‌های خود را صرفاً با ذکر بیت شاهد، نام شاعر و وزن شعر ارائه می‌دهد.

## راه‌اندازی محلی

```bash
git clone https://github.com/zorost/simorgh.git
cd simorgh
npm install
npm run dev
```

نشانی `http://localhost:5173` را در مرورگر باز کنید.
